CD Ready 1.0 · Windows 音频 CD 准备工具

选择文件夹 → 检查曲序与曲名 → 生成刻录文件。
默认沿用播放列表，也可按文件名、标签或手动排序；输出为“01 - 曲名.wav”。
按住任意曲目行上下拖动即可排序；绿色线表示插入位置，靠近上下边缘会自动滚动。
双击曲名可编辑。本地 AI 命名是可选功能，需先按 README.md 配置 local-ai.json。

原始文件保留；每次在输出位置新建文件夹，不覆盖原音频。
全部通过校验后，打开“刻录顺序.wpl”，将曲目加入刻录软件的“音频 CD”列表。
本程序不控制光驱、不自动刻盘。

44.1 kHz / 16-bit / 双声道无损来源保持 PCM 一致；其他规格需转换到音频 CD 标准，不能逐位无损。
使用 SoX 高精度重采样、三角抖动和必要的防削波衰减，不做响度归一化。
MP3 等有损来源转 WAV 不能恢复已丢失的信息。

需要 Windows 10/11 x64、.NET Framework 4.8，以及含 libsoxr 的 FFmpeg full 和 FFprobe。
点“设置工具”选择 FFmpeg bin 文件夹；FFmpeg 需另行安装，本项目不附带这些二进制。

详细用法、音质边界、构建与测试方法见 README.md。
