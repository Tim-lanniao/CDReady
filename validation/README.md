# 验证

`test.ps1` 生成合成正弦波、浮点、单声道、24-bit / 96 kHz、MP3 和损坏 FLAC 等输入，通过同一个处理引擎验证转换与完整性。覆盖播放列表顺序、自然排序、曲名清理、PCM 一致性、防削波、取消、容量及外部 XML 实体拦截。

所有生成的音频、结果 JSON 和测试 EXE 都已忽略，不上传音乐文件。

`AiCheck.cs` 是可选本地模型联调测试，需要自行配置 `local-ai.json`，不包含在普通测试中。可用 .NET Framework `csc.exe` 编译并引用 `CDReady.exe`；将结果 JSON 路径作为唯一参数传入。它会根据配置按需启动和停止本地模型。
